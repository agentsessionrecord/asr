## Outputs

- OpenTelemetry: OTLP traces and logs.
- Tables: Parquet and Arrow, with DuckDB queries and loader examples for ClickHouse, BigQuery and Snowflake.
- SIEM: OCSF events, with request files for Splunk, Datadog and Elastic.
- Search: OpenSearch or Elasticsearch bulk data, and vector chunks for Qdrant. Vectors need an embedding command you supply.
- Git notes and Git AI: edit evidence kept apart from commit evidence.
- `Langfuse`, Braintrust and Phoenix: trace and dataset import files.
- Evals: dataset rows with source citations. Ordinary observed output is never marked as a passed test or a verified expected answer.

## Limits

Missing models, costs, counts, outcomes and times stay unknown. Copied records add no usage, and session totals are kept apart from the sum of model calls.

Content defaults and memory limits differ by exporter. Some can send data to a destination when you configure them to, and others only write local files. Check the README before you include content or run a loader. Exporting does not make private data safe to share.

## Test results

All exporter tests ran against local services, local containers or synthetic repositories, with synthetic embeddings for search. Production Splunk, Datadog, Elasticsearch, BigQuery, Snowflake, Git AI, hosted observability services and production embedding models are untested.
