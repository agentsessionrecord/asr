The viewer is a static page for reading Agent Session Record (ASR) files. Build it as its README describes, open `apps/viewer/dist/index.html` in a current browser and choose local files or a folder. It needs no server and makes no network requests. The CLI has no `asr view` command.

The editor plugins call `asr blame` and bundle the same viewer. The GitHub and GitLab apps build review summaries from local stores you configure.

## What the views show

The timeline shows messages, tool calls, decisions, model calls, changes, settings and gaps in file order, without counting copied records twice. The editor and review views keep edit evidence apart from commit evidence. Recorded commands and URLs are shown as text and never run or loaded. The viewer does not validate files or convert native logs.

## Test results

The viewer passed offline Chromium tests with every sample file, hostile content and a 220 MiB file. The VS Code extension passed host checks on VS Code 1.109.0. The JetBrains plugin was tested in the IntelliJ platform harness, but its JCEF dialog rendering was not. The GitHub and GitLab apps were tested only against local mocks and synthetic repositories.
