## What each source provides

Anthropic transcript exports can keep messages and tool calls. Copilot usage records give API evidence, not full chat history. The Codex compliance log importer was built from documented and synthetic field profiles, without a live Enterprise export. Missing or unsupported content is declared as a loss.

The telemetry importer adds explicit approval events to session records you supply. It does not treat a successful tool call as approved. Codex can leave out refusal events, so decision counts may be incomplete.

The Entire importer reads checkpoints from local Git data, on both of Entire's storage backends. It maps Entire's normalized transcript, so it covers every agent Entire supports. Install the Entire external command to run it as `entire asr export`. Live runs used the released Entire 0.13.2 CLI with scripted hooks and with real Claude Code and Codex sessions.
