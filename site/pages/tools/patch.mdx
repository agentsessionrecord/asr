title: "Native export integrations"
description: "Source patches, plugins, extensions and skills that add native export to agents."
---

Each package adds Agent Session Record (ASR) export to one agent and is pinned to the upstream commit it applies to. Most are source patches. OpenClaw uses a plugin, Pi an extension, NanoClaw a skill and DeepSeek Harness a community plugin. Each README covers setup, commands and checks. The [package overview](https://github.com/agentsessionrecord/asr/blob/main/upstream/README.md) explains the layout and the package checks.

Project checks are the agent's own build, tests, lint and type check for the changed code, plus validation of a synthetic session exported by the patched agent. The OpenCode, Goose and Hermes packages were also tested with a live Claude model on November 5, 2026. In each run the patched agent read files, edited one and ran a test, and its export validated with no errors. No other package has been tested against a live model.

As an example, the OpenCode patch adds `opencode session export SESSION_ID --format agent-session`. It needs `OPENCODE_AGENT_SESSION_HISTORY=1` set before the session is recorded, and an existing server has to restart with that setting.

Stored history can lack approvals, model inputs, usage, file changes, commits and relationships, and each export declares what it leaves out. A valid export does not show that capture was complete or that the file is safe to share.
