Each package adds ASR export to one agent. It is pinned to the upstream commit
it applies to, and its README covers installation, commands, checks and what
the export leaves out. Most are source patches. OpenClaw uses a plugin, Pi an
extension, NanoClaw a skill and DeepSeek Harness a community plugin.

Project checks are the agent's own build, tests, lint and type check for the
changed code, plus validation of a synthetic session exported by the patched
agent. No package has been tested against a live model.

## Commands and capture limits

OpenCode uses `opencode session export SESSION_ID --format agent-session`.
Enable `OPENCODE_AGENT_SESSION_HISTORY=1` before recording and restart an existing
server. Kilo uses `kilo export SESSION_ID --format agent-session`. Its V1 and V2
snapshot paths declare incomplete capture. Qwen Code uses
`/export agent-session [directory]`.

Codex uses `/export --format agent-session PATH` for saved local rollout
history. Markdown remains the default. Goose uses
`goose session export --session-id`. ForgeCode uses
`conversation dump --format agent-session`.

Xum exports one selected chat segment and declares the earlier part of the chat
missing. The NanoClaw skill exports one selected Claude SDK continuation,
including retained tools and identified model calls. The operator confirms
which NanoClaw session it belongs to. It does not capture mailbox delivery or
other providers. fx's homepage is [fx.sh](https://fx.sh).

Kimi Code uses `KIMI_CODE_EXPERIMENTAL_AGENT_SESSION_EXPORT=1 kimi export --format agent-session`.
The ZIP contains only its manifest and ASR. Hermes uses the existing
`--session-id` selector and positional output in its sessions export command.

OpenHands exports from Canvas 1.35.0. Warp exports saved conversations from its
persistence crate and leaves out recognized secrets. Grok Build's
`events.jsonl` telemetry and `updates.jsonl` ACP stream are separate sources.

Stored history can lack approvals, model inputs, usage, file changes, commits
and relationships. Each integration declares those losses. Successful
validation does not establish complete capture or suitability for sharing.
