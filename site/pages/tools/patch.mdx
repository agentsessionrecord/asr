read its README for installation, source contracts, checks and known losses.

replay compares trees and does not establish a successful upstream build.

are historical. Synthetic fixture validation and focused project checks are

## Commands and capture limits

OpenCode uses `opencode session export SESSION_ID --format agent-session`.
Enable `OPENCODE_AGENT_SESSION_HISTORY=1` before recording and restart an existing
server. Kilo uses `kilo export SESSION_ID --format agent-session`. Its V1 and V2
snapshot paths declare incomplete capture. Qwen Code uses
`/export agent-session [directory]`.

Codex has six reference commits. `/export --format agent-session PATH` exports
saved local rollout history. Markdown remains the default. Goose now lives at
`aaif-goose/goose` and uses `goose session export --session-id`.
ForgeCode lives at `tailcallhq/forgecode` and uses
`conversation dump --format agent-session`.

Xum lives at `coder/xum`. Its native patch exports one selected chat segment
with a prefix gap. The converter reads archives before active chat and preserves
legacy Mux names and roots. Pi lives at `earendil-works/pi`. NanoClaw lives at
`nanocoai/nanoclaw`. Its skill exports one selected Claude SDK continuation,
including retained tools and identified model calls. The operator confirms the
session association. It does not capture mailbox delivery or other providers.
fx lives at `vercel-labs/fx` with homepage [fx.sh](https://fx.sh).

Kimi Code targets the current TypeScript repository and protocol 1.5 store.
Use `KIMI_CODE_EXPERIMENTAL_AGENT_SESSION_EXPORT=1 kimi export --format agent-session`.
The ZIP contains only its manifest and ASR. Hermes uses the existing
`--session-id` selector and positional output in its sessions export command.

OpenHands targets Canvas 1.35.0. Pending PR #16174 touches the same dialog and
loader. A ready-for-dev issue and real Canvas end-to-end evidence are required
before submission. Historical SDK-only evidence does not satisfy that gate.
Mistral Vibe is reference code because community PRs are not accepted.

Warp covers the AGPL persistence crate. Its GH7834 product and technical specs
are unaccepted drafts. Product UI and lifecycle hooks remain outside scope.
Zed requires staff-confirmed discussion, human review and a CLA. Grok Build's
`events.jsonl` telemetry and `updates.jsonl` ACP stream are separate sources.
DeepSeek Harness accepts community plugins rather than external core PRs.

Stored history can lack approvals, model inputs, usage, file changes, commits
and relationships. Each integration declares those losses. Successful
validation does not establish complete capture or suitability for sharing.
Continue and Roo Code native patch packages have been retired. Their converters
remain available for saved logs.
