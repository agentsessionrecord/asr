---
title: "Convert native logs"
description: "Convert saved transcripts, documents and databases into private ASR streams."
---

Use `asr convert` for supported local agent history. It writes one ASR stream
per recorded native session. Use `asr agents` to list selectable names.

```sh
asr convert --agent codex ./native-history --out ./private-asr
asr validate --summary ./private-asr
```

Install the [CLI](/tools). Conversion reads local evidence in source order.
It does not start an agent, run recorded commands or follow recorded URLs.
Output can replace an earlier export of the same session after conversion
succeeds. Keep the files private.

## Default native log locations

These paths come from the CLI's [native discovery code](https://github.com/agentsessionrecord/asr/blob/main/crates/asr-collect/src/discovery.rs).
`asr convert` reads the input path you supply. These roots help you find it.
Pass a native file or a directory beneath the appropriate root.
The collector searches these roots when no explicit source is configured.

`~` means your home directory. `./` means the current working directory.
`$XDG_DATA_HOME` defaults to `~/.local/share`, `$XDG_CONFIG_HOME` to `~/.config`,
and `$XDG_STATE_HOME` to `~/.local/state`. An unset or empty override uses its default.
The paths below describe the discovery implementation. Other platforms or
installations can store history elsewhere. Supply that location explicitly.

The README lists every supported group and links its source profile, mapping,
fixtures and limits. A recorded tool outcome does not establish approval.
Settings, usage, edits and lineage appear only when native evidence supports them.
Unsupported fields, missing history, malformed input and size limits stay visible
through metadata, declared losses and gaps.
