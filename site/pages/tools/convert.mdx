---
title: "Convert native logs"
description: "Convert saved agent transcripts, documents and databases."
---

`asr convert` turns local agent logs into Agent Session Record (ASR) files, one per native session. `asr agents` lists the agent names it accepts. [Install the CLI](/tools) first.

```sh
asr convert --agent codex ./native-history --out ./private-asr
asr validate --summary ./private-asr
```

Conversion does not start the agent, run recorded commands or open recorded URLs. Output replaces an earlier export of the same session only after conversion succeeds. Keep the output private.

## Default native log locations

These are the roots the CLI's [discovery code](https://github.com/agentsessionrecord/asr/blob/main/crates/asr-collect/src/discovery.rs) searches. `asr convert` reads only the file or directory you pass it, and `asr collect` searches these roots when you configure no source.

`./` is the current directory. `$XDG_DATA_HOME` defaults to `~/.local/share`, `$XDG_CONFIG_HOME` to `~/.config` and `$XDG_STATE_HOME` to `~/.local/state`, and an empty override uses the default. Other platforms and installs can keep history elsewhere.

## Converter library

| Tool README | Live-test status |
| --- | --- |
| [ASR converter framework](https://github.com/agentsessionrecord/asr/blob/main/crates/asr-convert/README.md) | `not-applicable` |

The README links each agent's source profile, mapping, fixtures and limits. Converters add settings, usage, edits and lineage only when the native log has them, and report unsupported fields, missing history, malformed input and size limits as [declared losses and gaps](/spec/missing-data).

Goose and legacy Kiro sessions keyed by working directory need a stable installation namespace, set with `--namespace`. Records over the 16 MiB default limit can become gaps, and an incomplete last line waits for a later conversion.
