---
title: "Record new sessions"
description: "Capture sessions through agent hooks, model gateways and Agent Client Protocol messages."
---

Recorders write Agent Session Record (ASR) files while an agent runs. Agent plugins use the agent's own hooks, gateway recorders see model traffic and the ACP recorder sees the messages between an editor and the agent.

Most hook plugins leave out content by default. Where supported, `ASR_CONTENT=full` keeps the available text after filtering known secrets. Set `ASR_OUTPUT_DIR` to a private directory before you turn capture on. Gateway traffic includes prompts and the output sent to the model, and filtering cannot catch every secret.

## Writer libraries and shared recorder cores

Writer libraries add ASR output to your own agent or tool. They write what the caller passes in and cannot recover history the source never kept. The shared cores are installed together with an agent adapter.
