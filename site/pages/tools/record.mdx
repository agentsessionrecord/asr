description: "Capture supported agent hooks, gateway traffic and Agent Client Protocol exchanges."

Choose a recorder for the boundary you can observe. Agent plugins see native
callbacks. Gateway recorders see model traffic. ACP capture sees editor-to-agent
messages. Their capture limits differ.

Most hook plugins omit content by default. Where supported, `ASR_CONTENT=full`
retains available text after known-secret filtering. Set a private
`ASR_OUTPUT_DIR` and read the selected README before enabling capture.
Gateway traffic includes prompts and model-facing output. Filtering cannot
identify every secret.

## Agent plugins

Test status comes from the [repository registry](https://github.com/agentsessionrecord/asr/blob/main/registry.json).
`passed` names a tested path. `partial` means only part of the host path ran.
`not-live-tested` means no qualifying host or service run is recorded.
`not-applicable` applies to offline tools and shared libraries.
Read each README for the version, test scope and remaining limits.

The OpenCode package serves OpenCode, Kilo Code and MiMoCode. The Kimi recorder
supports separate Python 1.52 and 2.x contracts. Its live run covers 2.4.1.
Cline's run covers normal CLI act mode and the SDK local host. VS Code and CLI
yolo mode are untested. Mux requires managed installation, MCP enabling and
trusted workspace hooks. The Codex recorder's host run predates its latest
storage fixes. Those fixes have synthetic regression coverage.

Hook payloads can omit final arguments, final output, approval choices or
session lifetime. The READMEs state which facts are available. A turn stop does
not establish session end. Calls without a native join key remain unpaired.
Capture can stop at storage limits or lose callbacks. Loss markers describe
observed failures and do not establish complete delivery.

## Writer libraries and shared recorder cores

Install a writer when adding ASR to your own producer. Writers serialize facts
that the caller supplies. Generated types provide structure. Neither can
recover absent native history. Shared cores are installed through an adapter.
