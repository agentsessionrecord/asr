---

Send [issues](https://github.com/agentsessionrecord/asr/issues) and [pull requests](https://github.com/agentsessionrecord/asr/pulls) to the Agent Session Record (ASR) repository.

## Check a real mapping

Pick a native session with a prompt, an edit and a result you can inspect, convert it, and check that its IDs, order and tool links survive. Include a sample without secrets, the source version and the ASR you expect, and say what the source shows and what stays unknown. Useful cases include a person committing agent edits, a short commit ID, a failed tool, copied history and a later rebase.

## Improve the documentation

`spec/` defines the core, `guides/` covers integrations, `agents/` holds the agent list and converter notes, and site pages live in `site/pages/`. Use plain English and small JSONL examples with one record per line. Converter notes follow the [template](/agents#converter-notes-template) and say when a fact isn't documented.

## Propose a core change

Name the [overview](/spec/overview) question the change helps answer, the source data a producer can use and what a reader gets from it. Include a small example and the effect on existing readers. [Governance](/community/governance) explains when `_meta` or an extension fits better.
