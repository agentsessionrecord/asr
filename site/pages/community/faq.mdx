title: "FAQ"
description: "Answers about session records, conversion, blame and missing data."
---

## Is ASR a transcript format?

It is an indexable log of work. It records messages, tool activity, edits and commits as the source retains them. It does not reconstruct the exact request a model saw or prove that all history is present.

## Why not search the native logs directly?

You can, for one agent. Each agent stores sessions differently, so readers must rebuild search and blame logic for each format and keep it current as formats change. A converter holds that knowledge once. Readers then work across agents.

## Can an agent ship version 0.1 now?

Yes. Changes to 0.1 only add optional fields, record types and enum values. Requirement IDs and meanings stay fixed within a format version, and a breaking change gets a new `formatVersion`. The tools in this repository keep reading 0.1 files. The [Versions section](/spec/format#versions) defines what agent makers can rely on. From 1.0, a reader for 1.x reads every 1.x file. Later 1.x versions only add optional fields, record types and values. Readers preserve unfamiliar data and ignore meanings they do not understand.

## Must an agent write ASR itself?

No. A converter can read native logs after the session. An agent can supply an export command or write a second log in ASR. All three use the same records.

## Can I resume a session from it?

ASR does not define resume or replay. Native state may include model context or provider data that ASR does not retain. [Replaying sessions](/guides/replay) describes how recorded sessions can still support model and prompt comparisons.

## Does a commit record prove who wrote a line?

No. It can establish who performed a commit when the [repository checks](/spec/code#committed-by) pass. Line attribution also needs original, applied edits that match the commit. Readers report edited by and committed by separately.

## What if a person commits the agent's edits?

The reader can still match recorded edits to the commit's added lines. The [tour variant](/get-started/quick-tour#a-person-makes-the-commit) shows the same edit with a person's commit. The editor and committer are separate facts. A match supports attribution, but it is not proof.

## What happens after a rebase or squash merge?

Recorded rewrite pairs connect old and new commits. A squash commit can also be checked directly against surviving edit text. Similar commit subjects alone do not establish a rewrite.

## What if the source is incomplete?

Unknown fields stay absent. The header lists known losses, gaps show missing history, and shortened text is marked. A file with missing edits can still support text search.

## How are subagents counted?

Parent and child sessions reference one another when the source provides the link. Copies of parent records do not count as the child's own edits or cost. New model calls over inherited context belong to the child.

## Does a valid file mean it is safe to share?

No. Prompts, paths and tool results can contain private information. Producers exclude known secrets. Readers treat content as untrusted. Redaction creates a new file.

## Where do later results go?

Tests, outcomes and summaries learned after a session go in a separate [annotations file](/spec/annotations). They can be updated without changing the session stream.

## Can ASR help with audits?

Yes. It can link recorded approvals and policy settings to tool activity and code changes. A collector can preserve the received bytes and a receipt. Protecting the receipt separately can make later changes detectable. Local logs can change before collection. The [audit guide](/guides/audits) explains the limits and checks against independent systems.

## Does it work with ACP?

Yes. A [recorder](/guides/acp) can save a session that runs over ACP as ASR. Most sessions run without ACP, so converters read the logs agents already write.

## Can the format grow?

Vendor data uses `_meta` and namespaced record types. Named extensions can add fields and records while keeping the core meanings intact.
