Agent Session Record (ASR) is an open specification maintained by Wills Manley in its [public repository](https://github.com/agentsessionrecord/asr). Changes go through issues and pull requests.

## What belongs in the core

A feature belongs in the core when it helps answer the questions in the [overview](/spec/overview) and is cheap for a converter or agent to produce. A proposal should name the reader question and the native data that answers it without guessing. Review weighs implementation cost, behavior with missing data and whether readers will interpret the result consistently, and covers schemas, examples and validator behavior along with the text.

Data specific to one agent belongs in `_meta` or a namespaced record type. A feature readers can ignore without changing core meanings can go in a named extension, and storage tools keep its data.

## Guides and agent notes

Only the specification sets requirements. Guides explain integrations, and converter notes describe specific source versions and their limits, with a source or sample for each native fact. Listing an agent reserves its short name. It doesn't certify a converter or claim support for every version. These pages can change without a new `formatVersion`.

## Versions

Agent makers can build on 0.1 now. See [Versions](/spec/format#versions) for the compatibility rules.
