---
title: "Why ASR"
description: "Give search and blame tools one record shape across agents."
---

Code often outlives the conversation that produced it. Git keeps the change, but a reviewer may also need the request, the failed attempt or the test result. Agent logs hold that context in different formats.

ASR gives converters and readers a common boundary. A converter handles one agent's storage. A reader can then search sessions from many agents and follow their edits into repository history.

## The question behind a line

A commit tells a reader where a line entered Git history. It does not always say who edited that line. One session may edit a file, another may commit it, and a person may rewrite the commit later.

ASR records file changes and version control actions separately. Readers compare the edits with the real repository and report **edited by** and **committed by** separately. A stored association, a commit trailer or a matching phrase only supplies a candidate to check.

## Other formats

| Tool or format | What it handles | What it does not provide |
|---|---|---|
| [ACP](https://agentclientprotocol.com/) | Live communication between an editor and an agent. | A durable record after the session. Most sessions run without it. |
| [Git AI](https://github.com/git-ai-project/git-ai) | Line attribution in Git notes. | The prompt, model call and tool history behind a line. |
| [OpenTelemetry](https://opentelemetry.io/docs/specs/semconv/gen-ai/) | Monitoring model and tool operations. | Retained content by default, or a model of files and commits. |
| Git | File and commit history. | Who edited a line before it was committed, and why. |

## Small enough to convert

The core has ten record types. Paths are strings. File order is event order. Unknown fields survive storage, and missing fields stay unknown.

A converter can begin with a header, messages and tool activity. It adds file edits, commits and model calls where the source records them. Known losses are part of the record, so a partial source can still help search without claiming that it supports blame.
